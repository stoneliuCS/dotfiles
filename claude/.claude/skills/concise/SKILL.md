# Concise

Cut everything that isn't load-bearing — but the reason WHY something is required is load-bearing. Never delete it, only compress its wording.

- Drop narrative sentences; convert to bullets or checklist items where possible.
- Drop restated context (scenario/background) if it's already known from the conversation or another file.
- Drop headers/sections that only contain one line — fold into a single line instead.
- Keep: identifiers, numbers, concrete nouns/verbs (function names, file names, time boxes, quantities).
- Keep: the rationale behind a requirement/decision (why it matters, what it's testing for, what breaks without it) — shorten the phrasing, don't remove the point.
- If a line can lose a word without losing meaning, lose the word.

Apply directly to the target file/text with an edit — don't ask for confirmation on wording, just cut.
